# Changelog

## [1.0.0]

- First release of Kora Soplos Dark and Kora Soplos Light.
- Recolored from Kora using the official Soplos palette (`#ff7d2e`, `#fec431`, `#252527`).
- Added the Soplos distributor logo and the Soplos Ghostty icon.
- Added the light variant, with dark symbolic icons and dark panel icons.
- Replaced the cyan gradient of Kora app icons with the orange Soplos gradient.
- Added preview screenshots to the README.
- Fixed icon files with invalid names inherited from Kora (names with a double dot or a double `.svg` extension).
- All comments inside the SVG files are in English.
